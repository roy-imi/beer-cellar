# 选项资料库、常用选项与统一选择器

## 产品目的

新增酒窖入库或酒吧记录时，酒厂、啤酒风格和啤酒花属于高频重复字段。该模块通过“可维护的全部选项资料库 + 常用快捷项 + 系统生成的最近使用 + 完整搜索”减少重复输入，同时仍允许新建资料库中没有的值。

交互原型：[啤记常用选项选择器](https://beer-common-selector.roydrinkwaterli.chatgpt.site)

## 信息架构

- 主入口：`更多 → 设置 → 选项资料库`和`更多 → 设置 → 常用选项`。
- 场景入口：酒窖入库和酒吧打卡中的酒厂、风格、啤酒花字段。
- 上下文入口：每个选择器内的“管理资料库”和“管理常用”，管理完成后返回原选择器，并保留当次已选内容。
- 不新增底部页签，避免把录入辅助能力提升为独立业务模块。

## 选择器规范

| 字段 | 选择方式 | 保存值 | 特殊规则 |
| --- | --- | --- | --- |
| 酒厂 / 品牌 | 单选 | 原始酒厂名称 | 支持搜索和自定义输入，选择后立即返回表单 |
| 啤酒风格 | 单选 | 标准英文值或自定义值 | 列表主名称跟随中英文显示设置，选择后立即返回表单 |
| 啤酒花 | 多选 | 以逗号分隔的标准值或自定义值 | 已选项固定展示在顶部，点击“完成”后写回表单 |

选择器从上到下依次展示：

1. 搜索框；
2. 已选择项（仅啤酒花）；
3. 常用；
4. 最近使用；
5. 搜索结果或全部选项，并保留“管理资料库”入口；
6. 新建并保存入口；
7. 固定完成按钮（仅啤酒花）。

“全部选项”与资料库使用完全相同的数据，不再单独展示“我的资料库”区块。常用项和最近使用作为快捷入口展示；用户输入已收录的中文名、英文名或双语名时，系统统一保存为标准值，未收录内容按用户输入保存到资料库。用户从选择器新建值时，会同时完成“保存到资料库”和“用于当前记录”。

## 选项资料库管理

- 酒厂、风格、啤酒花分为三个内部页签，并展示各自数量。
- 可从系统标准项和最近使用建议中添加，也可直接输入自定义值。
- 首次使用会把产品内置的标准酒厂、风格和啤酒花初始化为资料库内容；初始化后，用户的删除和改名会被保留。
- 每个资料库选项可以设为常用、取消常用、修改名称或删除。
- 修改名称只更新资料库与对应常用项，不回写已有酒窖或酒吧记录。
- 删除资料库选项时会一并取消其常用标记，但不会删除或修改历史记录。
- 选择器中的“管理资料库”与设置页共用同一份数据；返回选择器后保留当次已选内容。
- 资料库新增、改名或删除后，“全部选项”立即同步，不存在第二份独立列表。

## 常用选项管理

- 酒厂、风格、啤酒花分为三个内部页签，并展示各自数量。
- 可从最近使用建议中快速加入，也可手动输入新的常用项。
- 重复项按大小写不敏感规则去重，输入首尾和连续空格会自动清理。
- 用户按住左侧把手拖动，可修改常用项在选择器中的先后顺序。
- “移除”只删除常用标记，不会修改任何已有酒窖或酒吧记录。
- 新增常用项时会自动将其收录到选项资料库；取消常用后仍保留在资料库中。

## 最近使用规则

- 最近使用不单独持久化，而是从酒窖与酒吧记录实时生成。
- 酒窖记录优先采用最近入库事件日期；酒吧记录采用饮用日期。
- 同一值只出现一次，按最近使用时间倒序展示。
- 删除历史记录后，最近使用会随当前数据自动更新。

## 数据与备份

- 常用项保存在设置数据的 `commonOptions` 中，包含 `breweries`、`styles`、`hops` 三个有序数组。
- 用户资料库保存在设置数据的 `optionLibrary` 中，同样包含 `breweries`、`styles`、`hops` 三个数组。
- 完整备份格式为版本 3，并包含设置数据；恢复备份时会一并恢复资料库和常用项。
- 旧版备份没有设置数据时仍可正常导入，且不会覆盖当前设备上的设置。
- 旧设置仅包含常用项时，升级后会自动把这些常用项补入资料库，避免取消常用后丢失候选值。
- 草稿继续保存表单原始值；加载草稿后，选择器会按当前显示语言重新生成展示名称。

## 验收要点

- 酒窖与酒吧使用同一套选择器和视觉状态。
- 单选字段选择后立即回填，多选字段必须点击完成才回填。
- 管理常用后返回原选择器，不丢失当次已选择的啤酒花。
- 管理资料库后返回原选择器，不丢失当次已选择的啤酒花。
- 自定义酒厂、风格和啤酒花可以预先保存、编辑、加入常用并进入备份。
- 中文或英文展示设置只改变界面名称，不改变历史记录的原始值。
- 常用项排序、删除、去重和备份恢复均通过发布检查。
